3. Implemented Backend Routes / API Endpoints
------------------------------------------------------------------------------
1. POST /api/auth/login
   - Public endpoint
   - Verifies credentials against bcrypt hash, issues signed JWT token (2h expiry)
   - Generic error messages to prevent user enumeration

2. GET /api/auth/me
   - Protected endpoint (Requires Bearer JWT)
   - Returns authenticated user details from token

3. POST /api/applications
   - Protected endpoint (Student role only)
   - Validates input, saves new scholarship application, returns sequential ID

4. GET /api/applications
   - Protected endpoint (Student & Officer)
   - Role-aware filtering: Student receives only their own records; Officer receives entire queue

5. PATCH /api/applications/:appId/status
   - Protected endpoint (Officer role only)
   - Updates status (Approved / Rejected); student attempts are blocked with HTTP 403 Forbidden

6. GET /api/health
   - Public health check confirming server and database availability
